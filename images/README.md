# 作品画像

公開する作品をこのフォルダにアップロードしてください。各シリーズ3点、計21点です。

ファイル名は必ず小文字の英字＋連番、拡張子 `.jpg` です。

- circuit-01.jpg ～ circuit-03.jpg
- quantum-01.jpg ～ quantum-03.jpg
- field-01.jpg ～ field-03.jpg
- flow-01.jpg ～ flow-03.jpg
- structure-01.jpg ～ structure-03.jpg
- morphology-01.jpg ～ morphology-03.jpg
- dimension-01.jpg ～ dimension-03.jpg

GitHubの `images` フォルダで **Add file → Upload files** を使えます。ブラウザ内の「画像を選ぶ」は一時プレビューで、GitHubへの保存ではありません。
