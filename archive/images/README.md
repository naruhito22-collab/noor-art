# 作品画像

公開する作品をこのフォルダにアップロードしてください。各シリーズ3点、計21点です。

ファイル名は必ず小文字の英字＋連番、拡張子 `.png` です。

- circuit-01.png ～ circuit-03.png
- quantum-01.png ～ quantum-03.png
- field-01.png ～ field-03.png
- flow-01.png ～ flow-03.png
- structure-01.png ～ structure-03.png
- morphology-01.png ～ morphology-03.png
- dimension-01.png ～ dimension-03.png

GitHubの `images` フォルダで **Add file → Upload files** を使えます。ブラウザ内の「画像を選ぶ」は一時プレビューで、GitHubへの保存ではありません。
